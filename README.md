# 🎓 Quizify – Study Smarter, Not Harder

Quizify is a modern, web-based academic study platform designed to make learning, examination preparation, and academic progress tracking easier and more organized.

It provides students with a centralized workspace where they can manage course materials, generate practice MCQs, attempt interactive quizzes, analyze their performance, and calculate their GPA.

**Study from your own material, with less friction.**

## ✨ Key Features

### 🔐 User Authentication
- Account registration and login.
- Email-based account management.
- Password hashing for local accounts.
- Logout functionality.
- Automatic session restoration.
- Google authentication integration structure.

### 📚 Course Material Management
- Upload course materials.
- Support for PDF, DOCX, and TXT files.
- Drag-and-drop file upload.
- File size management up to 100 MB.
- View and organize uploaded materials.
- Remove unwanted files.

### 📝 MCQ Quiz Generation
- Generate practice quizzes from uploaded study materials.
- Customize the number of questions from 1 to 30.
- Choose quiz difficulty:
  - Easy
  - Medium
  - Hard
  - Mixed
- Gemini model selection interface:
  - Gemini 2.5 Flash Lite
  - Gemini 2.5 Flash
  - Gemini 2.5 Pro

### 🎯 Interactive Quiz System
- Attempt multiple-choice questions.
- Four-option question interface.
- Instant answer feedback.
- Correct and incorrect answer highlighting.
- Automatic score calculation.
- Save completed quiz results.

### 📊 Academic Analytics
- Track completed quizzes.
- View previous quiz scores.
- Monitor academic performance.
- Review quiz completion dates.

### 🎓 GPA Tracker
- Add university courses.
- Enter course credit hours.
- Select grades using a 4.0 GPA scale.
- Calculate weighted GPA automatically.
- Maintain academic course records.

### 🎨 Modern User Interface
- Responsive dashboard.
- Light and dark mode.
- Clean academic workspace.
- Sidebar navigation.
- Interactive notifications.
- Mobile-friendly layout.

### 🏛️ University Study Toolkit
- University feature-interest selection.
- University name submission interface.
- Suggestions for future academic tools.
- Flashcards and study planner feature requests.

## 🚀 Getting Started

1. Download or clone the Quizify repository.
2. Open the project folder.
3. Launch the HTML file in a modern web browser.
4. Create an account.
5. Access your academic dashboard.
6. Upload your course materials.
7. Configure your quiz settings.
8. Generate and attempt practice quizzes.
9. Monitor your results and calculate your GPA.

## ⚙️ Current Project Status

Quizify is currently a standalone browser-based prototype.

The application supports local account management, course material uploads, TXT-based demonstration quiz generation, interactive MCQ practice, score tracking, and GPA calculation.

Some advanced features are not yet fully implemented:

- PDF and DOCX content extraction.
- Actual Gemini AI-powered question generation.
- Production-ready Google authentication.
- Backend and database integration.
- Cloud storage and cross-device synchronization.
- Remote university waitlist submissions.

The Gemini model options and Google authentication interface currently require additional integration.

## 🎯 Project Vision

Quizify aims to transform traditional examination preparation into a more interactive and organized learning experience.

The platform is designed to reduce the effort required to organize study resources, prepare practice questions, and monitor academic progress.

Its long-term vision is to become a comprehensive academic companion for university students, helping them study smarter, practice consistently, and achieve better academic outcomes.
